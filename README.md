# Adventure Chess

Adventure Chess is a card add-on for chess. This repo contains the web app.

- Live app: https://hdunkel.github.io/adventure-chess/
- Credit: the chess piece silhouettes are the Cburnett set (Wikimedia Commons), used with credit.

## Run the app on your computer

1. Install [Node.js](https://nodejs.org/) (LTS).
2. Install the dependencies: `npm install`
3. Start the app: `npm run dev`
4. Run the tests: `npm test`
